# Template Repository

This is a template repository with branch protection enabled by default.

## Features

- ✅ Main branch protection enabled
- ✅ Prevents direct pushes to main
- ✅ Allows self-merging PRs
- ✅ Blocks force pushes and branch deletion

## Using this template

1. Click "Use this template" button on GitHub
2. Create your new repository
3. The new repo will inherit the branch protection settings

## Branch Protection Settings

- **Direct pushes**: Blocked
- **Force pushes**: Blocked
- **Branch deletion**: Blocked
- **Required reviews**: None (allows self-merging)
- **Enforce for admins**: No (allows admin merging)
